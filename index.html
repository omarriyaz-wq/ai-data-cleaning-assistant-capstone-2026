Failure Mode 1

The Silent dropna() Catastrophe

AI Generated Code (Zero-Shot)

# Clean missing values
df.dropna(inplace=True)

What Happened: Phone number had 38% nulls, income had 30%, email had 25%. Dropping rows with ANY missing value resulted in only 16 rows remaining out of 1,260!

Defensive Production Fix

# Only drop on non-nullable primary keys
df = df.dropna(subset=['customer_id'])

# Handle optional fields non-destructively
df['phone_number'] = df['phone_number'].fillna('Not Provided')

Result: Retains 1,173 valid records (93.1%) while cleanly tracking missing attributes without data destruction.

Failure Modes 2 & 3

Semantic Blindspots: Refunds & Names

Financial Logic Inversion

df['purchase_amount'] = df['purchase_amount'].abs()

Negative amounts represent merchandise returns and refunds. Taking the absolute value flipped returns into sales, creating a $170 revenue distortion per refunded customer.

Cultural Name Mutilation

df['name'] = df['name'].str.replace(r'[^a-zA-Z\s]', '')

The naive regex stripped apostrophes and hyphens: O'Connor became OConnor; Jean-Luc became JeanLuc. Destroys CRM customer identification!

Solution Architecture

Automated Reusable Pipeline

1. Key Normalization

Normalizes casing and strips whitespaces on primary keys BEFORE executing deduplication.

2. Semantic Handlers

Preserves negative signs for accounting refunds; handles k and m multipliers.

3. Subgroup Imputation

Conditions salary imputation on Country + Age cohort, avoiding variance collapse.

4. Lineage & Audit Log

Emits execution time, dropped count, and imputed counts in an auditable JSON summary.

Key Takeaways

The 3 Golden Rules for AI Cleaning

Rule 1: Never Use Zero-Shot Prompts for Data Pipelines

Always supply an explicit data schema contract. Forbid global dropna() and specify date formats (dayfirst=True).

Rule 2: AI Has No Domain Intuition — Define Semantics

Clarify whether negative values represent refunds or typos. Clarify whether nulls in contact fields are optional or errors.

Rule 3: Enforce Automated Verification & Lineage

Every data cleaning function must return an audit log. Validate row retention and statistical drift before committing to production.
